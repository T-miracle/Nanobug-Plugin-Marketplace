# 02：历史版本、下载统计与安全升级提示

状态：ready-for-agent，已发布为 [#3](https://github.com/T-miracle/Nanobug-Plugin-Marketplace/issues/3)；尚未实施。稳定标识：`plugin-marketplace-v1-02`。

## Parent

[规格 #1：初版插件市场与官方插件独立分发](https://github.com/T-miracle/Nanobug-Plugin-Marketplace/issues/1)。

## What to build

用户能比较历史版本和更新日志，首次安装时选择兼容旧版，已安装后看到升级红点并明确触发更高兼容版本更新。作者撤回、附件失效、权限变化或升级失败都有可理解的结果；下载次数来自 GitHub 附件汇总并说明统计时间和口径。

## Acceptance criteria

- [ ] 版本列表展示全部收录历史、说明、兼容原因和撤回记录；默认选择最高兼容稳定版本，而不是无条件使用 latest。
- [ ] 首次安装可以选择旧兼容版，已有插件只能从市场升级至更高兼容版；禁用同版本重装、降级、不兼容和撤回版操作。
- [ ] 历史版首装与升级均以所选版本经审核登记的 SHA-256 核对下载的完整 ZIP 字节。同名 Release 附件缺失或重传为不同字节时，分别报告无法下载或摘要不符并拒绝安装/升级；既有安装版本与受管数据保持不变。
- [ ] 同一插件 ID 与包版本的审核摘要不可修改。即使源码 commit 未变，重新打包所得 ZIP 的摘要不同也必须提升包版本、提交新的 PR 审核；摘要一致只证明与审核 ZIP 字节相同，不作为源码可复现构建的证明。
- [ ] 编辑器启动后异步检查，长时间运行目标每六小时再检查，管理器按新鲜度刷新并支持手动刷新；检查不自动下载或更新。
- [ ] 有更高、兼容且未撤回的可用版本时标题栏插件按钮显示红点；查看管理器不清除，更新成功或无可更新项时清除。检查失败保留带时间的最后结果。
- [ ] 目录失败的只读缓存门禁同时覆盖升级；恢复后按最新版本、平台、能力和撤回状态重新判断，不能沿用先前可安装标志。
- [ ] 更新新增权限再次确认，无新增权限不重复授权；拒绝、取消、准备、迁移和激活失败保留旧版本及受管数据，成功更新按生命周期清理旧资源。
- [ ] 撤回条目从默认搜索移除，历史和已安装页可看原因，不远程卸载或禁用。附件失效与摘要错误明确失败，不回退为安装未知包。
- [ ] Actions 目标每六小时汇总实际插件包附件；展示版本和累计次数及时间。排除源码/校验文件，说明包含重复和市场外下载；任务失败保留旧值，无旧值显示暂不可用。
- [ ] 统计失败不等于目录刷新失败，不单独阻止安装；下载次数排序使用同一公开统计数据，不调用逐插件实时 API。
- [ ] 完成本单新增原生版本页、更新日志、统计状态和红点的相关交互验收。

## Testing and evidence

主责验收：M08、M09、M10、M15、M16、M17、M18、M20。
主责用户故事：12、13、14、15、16、17、18、20、23、26、27、28、29、37、38、47、48。

复用 01 的目录/下载夹具，新增多版本兼容矩阵、可控时钟、红点生命周期、撤回和恢复；更新链路执行新增权限拒绝、取消及数据事务故障的针对性测试。用同一源码内容但 ZIP 元数据不同的两个包模拟同名附件替换，验证所选历史版和升级均拒绝不同摘要、保留旧版本与数据；沿用 01 的注册表不可变校验，不重复完整首装负面矩阵。统计流程用可控 API 响应验证正确附件筛选、累加、失败保留和时间标注。新规则以输入输出测试覆盖，实际 Manager 升级至少覆盖声明式和 WASM 候选。只有共享下载、权限或准入路径变化才重跑 01 的受影响用例，不人工再演整套首次安装。最后完成共同交付门禁。

共同交付门禁：先完成受影响模块针对性测试；涉及宿主 Rust 时，在宿主仓库执行 cargo fmt --check、cargo test --workspace --exclude editor-app、cargo check --workspace。市场仓库运行实际技术栈的格式、契约与集成检查；纯文档验证路径、编号和差异，不执行无关 Rust 构建。涉及原生应用追加相关应用测试及真实交互；实际 WASM 先准备夹具再显式执行 ignored 场景。保持各步骤可编译，必要预重构先保行为验证。记录提交/工作树、包摘要、SDK/工具链、实际命令、结果和未验证限制；未验收不关闭。

## Boundaries

不实现任意市场源、评分、付费、预发布版、自动更新、市场降级或重装；不把统计失败升级为准入失败。
