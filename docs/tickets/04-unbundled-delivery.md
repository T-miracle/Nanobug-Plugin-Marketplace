# 04：取消随附、移除示例并完成 Windows 交付验收

状态：ready-for-agent，已发布为 [#5](https://github.com/T-miracle/Nanobug-Plugin-Marketplace/issues/5)；尚未实施。稳定标识：`plugin-marketplace-v1-04`。

## Parent

[规格 #1：初版插件市场与官方插件独立分发](https://github.com/T-miracle/Nanobug-Plugin-Marketplace/issues/1)。

## What to build

全新安装的 Nanobug 不再携带插件或主动推荐，用户从市场自行安装；已有用户的插件、设置和数据继续可用。迁移受示例和主仓库插件源码影响的测试后，移除这些源码及随附发行依赖，并用最终安装器/便携包完成一次 Windows 组合验收。

## Acceptance criteria

- [ ] 先盘点所有依赖迁出插件、示例源码和随附目录的构建、测试、资源及发行入口，给出迁移前后覆盖对应关系。
- [ ] 在原输入仍可用时先建立固定版本正式包或专用夹具，验证关键消费者，再删除六类现有示例源码和迁出的正式插件业务实现；若实际示例清单变化，按依赖盘点核对，不猜测目录。
- [ ] 替代夹具使用通用公开包/SDK/Manager 接缝，保留原 API、权限、生命周期、UI 与业务回归覆盖；不得靠删除测试、扩大忽略或专属宿主接口变绿。
- [ ] 安装器和便携分发不再携带插件包或要求同级插件目录，在线市场不再回退随附目录；清理旧随附推荐，用户自行打开市场安装。
- [ ] 全新无插件环境保留纯文本编辑、内置终端和默认主题；没有语言插件时不承诺对应识别、高亮或语言服务。首次离线没有市场缓存时给出明确结果。
- [ ] 升级既有编辑器时保留用户已安装插件、身份、设置、私有数据及本地导入；删除示例源码不自动卸载用户已有示例或删除其数据。
- [ ] 双语运行/构建/打包说明及安装器说明反映真实分发；源码注释与当前行为一致，不恢复已退役文档站或脚本入口。
- [ ] 最终短组合包含无随附安装 → 市场取包 → 使用能力 → 发现升级红点 → 查看历史/更新日志 → 升级 → 模拟目录失败门禁 → 恢复/撤回提示；读取正式包统计并确认更新时间。
- [ ] 对最终变化界面补充中英文、深浅主题、键盘焦点、中文输入、滚动和缩放验收；此前未变化控件不再逐项人工全测。
- [ ] 完整记录 Windows 实测、三项仓库门禁、受影响应用测试、实际 WASM ignored 场景以及未验证平台；其他平台不宣称已通过。

## Testing and evidence

主责验收：M06、M22、M23、M24、M25。
主责用户故事：53、54、55、56、57。

主责是删除与发行变化：测试引用闭包、替代夹具覆盖、干净安装器/便携环境、旧用户数据保留和一次最终组合。重跑所有受迁移/删除直接影响的测试及相关消费者，不只检索无旧路径就宣称通过。01/02 的完整负面矩阵继续作为自动回归资产，相关代码未变时引用证据，不再手工重演；集成导致调用路径变化必须重跑对应自动测试。真实包构建输入未变则复用已校验产物；私有数据和授权状态必须隔离。最后执行共同交付门禁并汇总 M01–M26 的实际结果，未解决项不关闭工单。

共同交付门禁：先完成受影响模块针对性测试；涉及宿主 Rust 时，在宿主仓库执行 cargo fmt --check、cargo test --workspace --exclude editor-app、cargo check --workspace。市场仓库运行实际技术栈的格式、契约与集成检查；纯文档验证路径、编号和差异，不执行无关 Rust 构建。涉及原生应用追加相关应用测试及真实交互；实际 WASM 先准备夹具再显式执行 ignored 场景。保持各步骤可编译，必要预重构先保行为验证。记录提交/工作树、包摘要、SDK/工具链、实际命令、结果和未验证限制；未验收不关闭。

## Boundaries

不重新设计已交付目录/下载/版本体系，不重做完整 Rust 合并，不远程卸载插件，不为减测试次数跳过删除所影响的真实消费者。
